Somos uma dupla. Um cuida dos anúncios no Instagram, no Facebook e no Google. O outro cuida do site, do rastreamento e das automações.

- **Anúncios** no Instagram, no Facebook e no Google, com público da sua região
- **Site e página de vendas** feitos para o celular, com botão de WhatsApp
- **Rastreamento** com pixel, API de Conversões e UTMs, para saber qual anúncio trouxe cada contato
- **Relatório semanal** com quanto foi investido, quantas conversas chegaram e quanto custou cada uma
